# PicTayo — Learning log

Use this to record concepts you can now explain, commands you practiced, and questions to revisit.

## Lesson 1 — Project scaffolding (2026-10-30)

- **Learned:** Difference between React (UI), TypeScript (types), Vite (tooling), and ESLint (static analysis).
- **Issue faced:** Vite generated a dependency combination whose TypeScript range was incompatible with `typescript-eslint`; resolved by selecting a compatible TypeScript version.
- **Practiced:** `npm install`, `npm run dev`, `npm run lint`, `npm run build`.

## Lesson 2 — Git basics (2026-10-30)

- **Learned:** Local repository vs GitHub remote; staging vs commit vs push; local commit author identity.
- **Practiced:** `git init`, `git status`, `git add`, `git diff --cached`, `git commit`, `git push`.

## Lesson 3 — Branching and review (2026-10-30)

- **Learned:** A feature branch isolates change; a pull request compares it against `main`; a merge incorporates reviewed changes.
- **Completed:** [PR #1](https://github.com/Nandoi/pictayo/pull/1) merged into `main`.

## Lesson 4 — Planned: responsibilities and documentation

- **Goal:** Explain why browser camera access, React hooks, photo-session state, templates, and PNG export should have different responsibilities.
- **Questions:** When is a custom hook useful? Why not put everything in `App.tsx`? What makes a task "done"?
